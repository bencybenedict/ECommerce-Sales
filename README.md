
# E-Commerce Sales Analysis

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn

## Project Description

Analyzed e-commerce sales data using Python to identify sales trends, top-performing products, and business insights. Performed data cleaning, exploratory data analysis (EDA), data aggregation, and data visualization to understand sales performance and support data-driven decision-making.

## Key Tasks

* Cleaned and preprocessed sales data.
* Performed exploratory data analysis (EDA).
* Used Pandas and NumPy for data manipulation and aggregation.
* Analyzed sales trends and product performance.
* Created visualizations using Matplotlib and Seaborn.

## Objective

To extract meaningful insights from e-commerce sales data and understand business performance through data analysis and visualization.
